INSTALL

装到桌面

装好之后，桌面会多一个「镜魇」的图标，点开就是全屏，和 App 一样；字卡依旧只存在这台设备里。

安卓 · Chrome 点右上角 ⋮，选「安装应用」或「添加到主屏幕」。
iPhone · Safari 点底部的分享按钮，往下找「添加到主屏幕」。
电脑 · Chrome / Edge 点地址栏右侧的安装图标，或在菜单里选「安装镜魇」。

没看到安装入口时，先确认是用 Chrome 打开的，并且地址以 https:// 开头。
